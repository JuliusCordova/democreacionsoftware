# Contracts — Stock Único

Este directorio contiene los contratos explícitos del producto.

## Tipos

- API contracts
- Event contracts
- Tool contracts para capacidades agénticas
- Integration contracts

## Regla

Los contratos se agregan progresivamente cuando una integración o boundary los requiere.

Para Sprint 0 no se define todavía un contrato de negocio concreto; el objetivo es establecer la ubicación y convención.

## Trazabilidad

Cada contrato deberá indicar, cuando aplique:

- SPEC / HU / RF relacionados;
- versión;
- productor/consumidor;
- esquema;
- idempotencia;
- errores;
- compatibilidad;
- pruebas de contrato.
